# Boîte à outils du modding de GTA V

## Documentation sur le modding du jeu GTA V : **[gta-subversion.eu](https://gta-subversion.eu/)**

## Expérimentations GTA V et FiveM

### Nos mods

| Mod | Touche | Fonctionnalité |
|---|---|---|
| [`change_ped`](https://github.com/PAD-EMD/gtamod-change-ped) | F1 | Changer le modèle du personnage, aléatoirement ou au choix |
| [`foule_throttle`](https://github.com/PAD-EMD/gtamod-foule-throttle) | F2 | Générer une foule de PNJ et la contrôler (apparence, animations) |
| [`player_position`](https://github.com/PAD-EMD/gtamod-player-position) | F4 | Afficher les coordonnées (x, y, z) du joueur |
| [`weapon_invoke`](https://github.com/PAD-EMD/gtamod-weapon-invoke) | F5 | Invoquer une arme dans la main du joueur |
| [`woopwoop_police`](https://github.com/PAD-EMD/gtamod-woopwoop-police) | F6 | Désactiver la recherche de la police |
| [`vehicle_settings`](https://github.com/PAD-EMD/gtamod-vehicle-settings) | F1 | Modifier le véhicule dans lequel est le joueur (couleurs, vitesse, adhérence, indestructibilité) |
| [`weather_and_time`](https://github.com/PAD-EMD/gtamod-weather-time) | F12 | Changer la météo et l'heure |
| [`waypoint_position`](https://github.com/PAD-EMD/gtamod-waypoint-position) | – | Afficher les coordonnées (x, y) du repère sur la carte |
| [`pnj_lab`](https://github.com/PAD-EMD/gtamod-pnj-lab) | `/gather` | Laboratoire d'expérimentation sur les PNJ (en cours de développement) |
| [`playable_camera_mod`](https://github.com/RobinMoretti/fivem-cinecam) | – | Caméra libre pour faire du machinima dans GTA V / FiveM |

`change_ped` et `vehicle_settings` utilisent tous les deux **F1** : pour les démarrer ensemble, change la touche de l'un des deux.
